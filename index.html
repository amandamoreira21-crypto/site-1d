HTML + CSS criando possibilidades

Por trás de cada página bonita, existe uma estrutura bem construida. A programação é o oceano de possibilidades que podemos explorar.

A internet também
começa com ideias.

Todo site que você visita tem uma estrutura e uma aparência. Duas tecnologias fundamentais ajudam a construir essa experiência: HTML e CSS. Vamos conhecer o papel de cada uma?

Assim como o mar precisa de uma estutura, todo site precisa de uma base. Essa base é o HTML.

01

HTML: a estrutura
da página.

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). Ele organiza o conteúdo de uma página, indicando o que é título, parágrafo, imagem, link e muito mais.

✳ Pense no HTML como a estrutura de uma casa: ele define onde cada parte fica.
● ● ● index.html HTML 
<!DOCTYPE html>
<html lang="pt-BR">
  <body>
    <h1>Olá, praia!</h1>

    <p>
      Bem-vindo ao nosso site.
    </p>

  </body>
</html>
Exemplo de uma estrutura HTML simples
● ● ● style.css CSS 
h1 {
    color: #087e8b;
    font-size: 36px;
    text-align: center;
}

body {
    background-color: #fff8e9;
    font-family: sans-serif;
}
Exemplo de estilização com CSS

Assim como as cores do pôr do sol transforma a paisagem, o CSS transforma a aparencia de uma página.

02

CSS: o visual
ganha vida.

CSS significa Cascading Style Sheets (Folhas de Estilo em Cascata). É responsável pela aparência do site: cores, fontes, tamanhos, espaçamentos, posicionamento e adaptação para diferentes telas.

✳ Se o HTML é a estrutura da casa, o CSS é a pintura, a decoração e o acabamento.

HTML e CSS: duas ferramentas, uma infindade de possibilidades.

Dois papéis. Um só resultado.

HTML e CSS se completam para criar páginas organizadas, bonitas e fáceis de usar.

</>
HTML

Exemplo: título, texto, imagem e botão.

CSS

Como aparece?
